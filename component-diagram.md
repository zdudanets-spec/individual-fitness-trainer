# Диаграмма компонентов

Диаграмма показывает основные части проекта. Сервер и база используют встроенные средства Python. Регистрация и сохранение данных с сайта будут подключаться по мере разработки.

```mermaid
flowchart LR
    User[Пользователь] --> Browser[Браузер]
    subgraph Project[Веб-приложение «Форма»]
        UI[Страница сайта<br/>HTML CSS JavaScript<br/>outputs/index.html]
        Server[Python-сервер<br/>backend/server.py<br/>http.server]
        SQL[Описание таблиц<br/>backend/schema.sql]
        DB[(SQLite<br/>data/forma.sqlite3)]
        Future[Будущие функции<br/>регистрация, план, история, привычки]
        Browser -->|HTTP-запрос| Server
        Server -->|возвращает страницу| UI
        Server -->|создаёт таблицы и работает с данными| DB
        SQL -->|структура базы| DB
        Server -. будут добавлены .-> Future
        Future -. чтение и запись .-> DB
    end
```

## Что делает каждая часть

- **Страница сайта** — то, что пользователь видит в браузере.
- **Python-сервер** — принимает запросы браузера и возвращает страницу или ответ.
- **Файл `schema.sql`** — описывает таблицы и связи базы данных.
- **SQLite** — файл на компьютере, где будут храниться данные проекта.
- **Будущие функции** — регистрация, анкета, тренировки и трекер привычек; они будут добавляться по плану.
