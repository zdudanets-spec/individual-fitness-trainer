# UML диаграммы последовательностей

Диаграммы описывают три основных сценария из требований: формирование плана, выполнение тренировки и просмотр прогресса. В них показано целевое взаимодействие браузера, Python-сервера, модулей приложения и SQLite.

## Сценарий 1 Формирование индивидуального плана

```mermaid
sequenceDiagram
    actor U as Пользователь
    participant F as Frontend
    participant B as Backend Python
    participant P as Модуль профиля
    participant T as Модуль тренировок
    participant D as SQLite
    U->>F: Открывает раздел Мои тренировки
    F-->>U: Показывает форму параметров
    U->>F: Заполняет цель, опыт, частоту и оборудование
    F->>B: Запрос сформировать план
    B->>P: Получить профиль пользователя
    P->>D: Прочитать параметры профиля
    D-->>P: Данные профиля
    P-->>B: Цель, уровень и ограничения
    B->>T: Подобрать план и упражнения
    T->>D: Получить подходящие упражнения
    D-->>T: Каталог упражнений
    T-->>B: План с расписанием и нагрузкой
    B->>D: Сохранить план пользователя
    D-->>B: Подтверждение
    B-->>F: План сформирован
    F-->>U: Отображает расписание и инструкции
```

## Сценарий 2 Выполнение и завершение тренировки

```mermaid
sequenceDiagram
    actor U as Пользователь
    participant F as Frontend
    participant B as Backend Python
    participant T as Модуль тренировок
    participant D as SQLite
    U->>F: Выбирает тренировку
    F->>B: Запросить детали тренировки
    B->>T: Получить план занятия
    T->>D: Прочитать упражнения и параметры
    D-->>T: Состав занятия
    T-->>B: Детали и техника упражнений
    B-->>F: Данные тренировки
    F-->>U: Показывает упражнения и инструкции
    U->>F: Отмечает выполнение и результаты
    F->>B: Сохранить результат/статус
    B->>T: Обновить тренировочную сессию
    T->>D: Записать дату, статус и результаты
    D-->>T: Подтверждение сохранения
    T-->>B: Тренировка обновлена
    B-->>F: Результат сохранён
    F-->>U: Показывает подтверждение и прогресс
```

## Сценарий 3 Просмотр прогресса

```mermaid
sequenceDiagram
    actor U as Пользователь
    participant F as Frontend
    participant B as Backend Python
    participant G as Модуль прогресса
    participant D as SQLite
    U->>F: Открывает раздел Прогресс
    F->>B: Запросить историю за период
    B->>G: Подготовить сводку пользователя
    G->>D: Получить тренировки, параметры и привычки
    D-->>G: Сохранённые записи за период
    G->>G: Рассчитать регулярность и динамику
    G-->>B: История и сводные показатели
    B-->>F: Данные прогресса
    F-->>U: Показывает историю и динамику
```
