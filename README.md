# Индивидуальные тренировки

Учебный проект адаптивного сайта с персональными тренировками и трекером привычек. Срок сдачи — 10 декабря 2026 года.

## Файлы проекта
- `index.html` — страница сайта.
- `server.py` — локальный Python-сервер и начальные адреса регистрации/входа.
- `schema.sql` — таблицы базы SQLite.
- `docs/weekly-plan.md` — общий понедельный план.
- `weekly/` — отдельный отчёт и статус по каждой неделе.

Для запуска не нужно устанавливать дополнительные библиотеки. На компьютере с Python открой терминал в папке проекта и выполни `python server.py` (либо `py server.py`). Затем открой http://127.0.0.1:8000/. Остановка: Ctrl+C.

## Текущее состояние
Сайт пока содержит демонстрационный интерфейс. Серверные адреса регистрации и входа добавлены как начальная работа третьей недели, но формы страницы ещё нужно подключить к серверу и пройти вручную. Это не готовая публичная система аккаунтов.

Подробные задачи и статусы находятся в `weekly-plan.md` и в папках `weekly/`. Не загружай в GitHub файл базы данных или настоящие пароли пользователей.
