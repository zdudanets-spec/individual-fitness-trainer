# Индивидуальные тренировки

Учебный проект веб-приложения для составления персонального плана тренировок. Пользователь регистрируется, заполняет анкету, выбирает предпочтительный формат занятий и получает расписание с упражнениями и инструкциями.

## Возможности

- Регистрация и вход с паролем, хранящимся в виде PBKDF2-HMAC-SHA256 хеша; сессии хранятся сервером и передаются через HttpOnly cookie.
- Профиль пользователя в SQLite: цель, уровень, частота тренировок, место занятий, предпочтения и ограничения.
- Генерация программы по выбранному формату (силовые, кардио, йога или растяжка), уровню подготовки, расписанию и условиям занятий.
- Просмотр дней программы и пошаговые инструкции к упражнениям. Для части упражнений доступны альтернативы.
- Отметка выполнения упражнений с сохранением статуса занятия и даты в SQLite.



## Требования

- Python 3.10 или новее (сторонние пакеты не нужны).
- macOS, Windows или Linux.

## Запуск на macOS или Linux

1. Скачай репозиторий и открой Терминал в папке проекта.
2. Перейди в папку проекта (если Терминал открыт в домашней папке):

   ```bash
   cd ~/Desktop/fitness-trainer-work
   ```

3. Запусти сервер:

   ```bash
   python3 server.py
   ```

4. Открой в браузере [http://127.0.0.1:8000](http://127.0.0.1:8000). Окно Терминала оставь открытым.
5. Чтобы остановить сервер, нажми `Ctrl+C`.

На Windows используй `py server.py` и затем тот же адрес в браузере.

При первом запуске рядом с кодом создаётся `data/forma.sqlite3`; схема применяется автоматически. Файл базы содержит персональные данные и не должен попадать в GitHub. Если порт 8000 занят, останови предыдущий экземпляр сервера.

## Структура проекта

- `index.html` — интерфейс приложения и клиентская логика.
- `server.py` — локальный HTTP-сервер, API аккаунта, профиля и тренировок.
- `schema.sql` — таблицы SQLite.
- `docs/` — техническое описание и диаграммы.
- `weekly/` — план и отчёты по неделям.

## Текущий статус и ограничения

Реализованы функции плана до седьмой недели: аккаунт, профиль, генерация и просмотр программы, отметка выполненных упражнений. Проект работает локально при запущенном Python-сервере; публичный хостинг не настроен. Перед сдачей рекомендуется вручную пройти регистрацию, вход, заполнение анкеты и отметку тренировки.
