# Форма — индивидуальные тренировки

Учебный проект сайта для составления плана занятий и учёта прогресса. Срок проекта — 10 декабря 2026 года.

## Что уже есть

- Страница-прототип: `outputs/index.html`.
- Сервер на обычном Python: `backend/server.py`.
- Описание таблиц SQLite: `backend/schema.sql`.
- Документы проекта находятся в `docs/`.

Для запуска не нужно устанавливать Flask, Django или другие библиотеки. Используются встроенные модули Python `http.server` и `sqlite3`. При первом запуске автоматически создаётся база `data/forma.sqlite3`.

## Как запустить на Windows

1. Открой папку проекта в Проводнике.
2. Открой в этой папке PowerShell или терминал.
3. Введи команду:

```powershell
py backend\server.py
```

Если команда `py` не сработала, попробуй `python backend\server.py`.

4. Пока сервер работает, открой в браузере `http://127.0.0.1:8000/`.
5. Чтобы остановить сервер, вернись в окно Python и нажми `Ctrl+C`.

Проверка сервера и базы доступна по адресу `http://127.0.0.1:8000/api/health/`.

## Технологии

Интерфейс: HTML, CSS и JavaScript. Сервер: Python без дополнительных библиотек. База данных: SQLite. История изменений: Git и GitHub.
