# Форма — индивидуальные тренировки

Учебный проект адаптивного веб-приложения для создания тренировочного плана и отслеживания прогресса. Целевой срок разработки — 10 декабря 2026 года.

## Текущий прототип

Откройте [`outputs/index.html`](outputs/index.html) в браузере. Здесь показаны главная страница, демо-регистрация и анкета, пример тренировки, а также счетчики воды, шагов и выполненных упражнений. Пока данные сохраняются только в браузере; сервер, SQLite, настоящая авторизация, история и полноценный прогресс ещё предстоит реализовать.

## Технологии целевой версии

Frontend: HTML, CSS, JavaScript. Backend: Python. База данных: SQLite. Репозиторий и история изменений: Git и GitHub.

## История разработки

Фиксируйте каждую завершённую задачу отдельным коммитом, например `feat: добавить сохранение профиля` или `docs: обновить план за неделю`. В конце недели обновляйте статусы и журнал в `docs/weekly-plan.md`, затем создавайте коммит. Не включайте в репозиторий пароли, токены и реальные личные данные.
