# Техническое задание: «Индивидуальные тренировки»

## 1. Назначение проекта
Сайт помогает пользователю заполнить анкету, получить подходящую тренировочную программу с описанием упражнений и отмечать тренировки, воду и шаги.

**Срок проекта:** до 10 декабря 2026 года.

## 2. Что должно быть в первой версии
- Регистрация, вход и выход.
- Профиль с целью, уровнем подготовки, графиком, оборудованием и ограничениями.
- Упражнения с инструкциями.
- Подбор плана по простым заранее заданным правилам.
- Отметки тренировок и история.
- Учёт воды и шагов.
- Хранение данных в SQLite.

## 3. Технологии
- Интерфейс: HTML, CSS и JavaScript в браузере.
- Сервер: Python и встроенный `http.server`.
- База данных: SQLite через встроенный `sqlite3`.
- Сторонние Python-библиотеки не требуются.

## 4. Текущий статус
В корне репозитория находятся `index.html`, `server.py` и `schema.sql`. Сервер отдаёт страницу сайта и проверяет соединение с базой. На третьей неделе добавлена начальная серверная основа регистрации, входа, выхода и сессий. Формы страницы пока нужно связать с этими адресами и вручную проверить.

## 5. Основные данные
В базе предусмотрены аккаунты, профили, упражнения, планы, тренировки, результаты занятий, измерения тела, ежедневные привычки и сессии входа. Структура описана в [модели данных](data-model.md).

## 6. Ограничения
Программа подбирает упражнения по учебным правилам и не заменяет врача или тренера. На первом этапе шаги вводятся вручную. Не использовать реальные пароли и личные данные при демонстрации.
